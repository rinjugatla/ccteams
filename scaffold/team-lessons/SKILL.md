# Team Lessons (this project)

Durable, project-specific additions to the active team's playbook. This skill is
**owned by this project**: ccteams scaffolded it once and never overwrites it,
so it survives team switches, removals, and package updates.

This file is the **index only**: a short entry per lesson, so consulting the
catalog costs a few lines of context per entry instead of the whole history.
Each entry leads with WHEN to read the lesson, so a scan can rule one out from
its first line without needing to recognize the exact original symptom. Each
lesson's body lives in `lessons/NN-slug.md`, and the index below is generated
from those files' frontmatter by `scripts/gen-lessons.mjs` — **do not edit
between the markers by hand**.

How to add or update an entry (frontmatter schema, the generator command, and
the learning loop) is in [`AUTHORING.md`](AUTHORING.md).
